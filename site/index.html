VW Diagnostics

Desktop diagnostics and performance dashboard for the VW 3.0 V6 TDI (Amarok DDXC). Live data, fault codes, and a tuning workflow measured against the factory torque envelope — not a tuner's word.

Download for Windows ⬇ Install guide

Windows 10/11 · installer ≈ 80 MB · also runs on macOS & Linux from source

Status: diagnostics and simulation. Live reads over J2534 — fault codes, live channels — are wired. Stock-flash read and calibration writes are gated behind OEM security access and are not implemented yet.

What you get

Everything runs on your machine

No cloud, no accounts, no phone-home. The monitor talks to the truck; nothing leaves your laptop.

Live

Streaming gauges

RPM, rail pressure, boost, coolant, pedal — streamed over J2534 at 10 Hz with plausibility checks and rate limiting on every channel.

Diagnostics

Fault codes & freeze frames

Read and clear DTCs with full freeze-frame context, plus diesel-specific analysis notes for the 3.0 TDI.

Not yet live

Stock ECU backup

The backup path is built and checksummed with SHA-256, but a real stock read needs OEM security access and the DDXC flash layout — in live mode the app refuses rather than pretending. Simulation writes a placeholder image so the path stays exercised.

Native stats

Learned baselines

EWMA baselines and z-score deviation per channel, learned from your own truck. It flags what drifts, not what a forum post says.

Verification

Sign-off against the factory ladder

Pulls are checked against the manufacturer variant ladder — 550 stock → 580 VW transient → 620 single-turbo Audi → 700 Nm ZF 8HP70 rating — with overboost overlay. Curves are labelled simulated reference data until the live transport is wired.

Anywhere

View from any device

The dashboard serves over your LAN. Laptop talks to the truck; your phone or tablet is the display.

Safety scope

Default-deny

The interface can only ever address two modules. Everything else is refused at the protocol layer — not hidden in the UI, blocked in code. Destructive actions require a typed confirmation. No calibration writes are implemented yet; the policy gates them for when they are.

✓ Engine ECU (0x7E0) ✓ Transmission ECU (0x7E1) ✗ Steering ✗ Brakes / ABS ✗ Airbags (SRS) ✗ ADAS ✗ Every other module
Install

Up in three steps

Works immediately in simulation mode — no hardware needed. Add a J2534 adapter later for live data.

Download & run the installer vw-diagnostics-setup.exe — standard Windows installer with desktop shortcut.
Open the app, press Start Monitor The dashboard boots in simulated self-check mode so you can explore everything before plugging into the truck.
Connect hardware when ready A J2534 adapter (e.g. Scanmatik 2) + the app's Python monitor gives you live ECU reads — fault codes and live channels. Flashing is not wired up: the app refuses the stock read until OEM security access is available.
